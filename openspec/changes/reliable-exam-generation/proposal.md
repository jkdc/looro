# Recuperar candidatos válidos en exámenes generados

El backend solicita candidatos extra, pero hoy puede descartar una sección completa por un único candidato defectuoso. En inglés A1, una prueba aislada reprodujo tanto el fallo con cinco pasajes cuando se requieren seis como el fallo con siete válidos y uno malformado.

Implementar reparación acotada por déficit para inglés A1–C1, incorporar feedback real al reintento legado y registrar resultados por fase. Mantener formas, cobertura, diversidad, juez, publicación, contratos públicos y exámenes existentes. La evaluación con un proveedor real y el despliegue quedan fuera de este cambio.
